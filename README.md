# Research Methodology and Statistical Analysis Roadmap

Static GitHub Pages website for the PhD course project.

## Structure

- `index.html` - Main homepage.
- `pages/` - All website pages in one place.
- `assets/files/` - Repository of downloadable Word, PDF, SPV, Excel, and reference files.
- `assets/images/` - Website images, including the research model.
- `style.css` and `script.js` - Shared site assets.

## Publishing

Push this folder to GitHub and enable GitHub Pages from the `main` branch, root folder.
